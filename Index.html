Busca Binária

WIntegrante: Wesley

O que é?

Algoritmo utilizado para encontrar um elemento em uma lista ordenada.

Como funciona?

  1. Analisa o elemento central da lista.
  2. Compara o valor central com o valor procurado.
  3. Descarta a metade que não contém o elemento.
  4. Repete até encontrar o valor ou concluir que ele não existe.

Quick Sort

JPIntegrantes: José Igor e Pablo

O que é?

Algoritmo de ordenação baseado na estratégia de divisão e conquista.

Como funciona?

  1. Escolhe um elemento chamado pivô.
  2. Organiza os elementos menores de um lado.
  3. Organiza os elementos maiores do outro lado.
  4. Aplica o mesmo processo recursivamente nas partições.

Exemplo visual

Eficiência

Melhor casoO(n log n)
Caso médioO(n log n)
Pior casoO(n²)

Shell Sort

MIntegrante: Matheus

O que é?

Algoritmo de ordenação que utiliza intervalos entre os elementos para organizar a lista.

Como funciona?

  1. Começa utilizando um intervalo entre posições.
  2. Compara elementos separados por esse intervalo.
  3. Reduz progressivamente o intervalo.
  4. Finaliza com intervalo igual a 1.

Exemplo visual

Eficiência

O desempenho depende da sequência de intervalos utilizada.Não existe uma única complexidade aplicável a todas as implementações.

Selection Sort

VIntegrante: Victória

O que é?

Algoritmo de ordenação que seleciona repetidamente o menor elemento da parte ainda não ordenada.

Como funciona?

  1. Percorre a lista procurando o menor elemento.
  2. Coloca o menor elemento na posição correta.
  3. Repete o processo com os elementos restantes.
  4. Continua até ordenar toda a lista.
